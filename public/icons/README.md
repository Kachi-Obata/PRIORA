# PWA icons

Place two PNG files here before deployment:

- `icon-192.png` — 192x192
- `icon-512.png` — 512x512

Both should use the Priora brand color (`#0d9488`) with a simple, legible
mark. Transparent background or solid `#f4f4f6` both work.

Until real icons are added, the PWA will still install but the home-screen
icon will fall back to a browser placeholder.
